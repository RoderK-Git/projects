# Elena N1

**Status:** Frühes Spielkonzept · Narrative Science-Fiction · Arbeitstitel *Elena N1*

## Prämisse
Der Spieler erwacht ohne Wissen über die eigene Situation in einem einzigartigen, technologisch überlegenen kybernetischen Körper. Dieser Körper wurde von einem mächtigen Waffenindustriellen für seine todkranke Tochter entwickelt, aber von einem leitenden Ingenieur gestohlen, um dessen eigene, nach einem Unfall komatöse Tochter zu retten. **Das Bewusstsein des Spielercharakters stammt nicht von der kranken Tochter des Industriellen.**

Im Zentrum steht kein festgelegter Heldenweg, sondern ein dynamisches Narrativ: Was macht ein Mensch, der plötzlich als erste und einzige derart fortgeschrittene kybernetische Lebensform existiert?
