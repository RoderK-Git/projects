# Gengineer — Genetic Engineer

**Status:** Konzept / Brainstorming, keine verbindliche Spezifikation.

Ein Sandbox-Spiel über das Erschaffen und Zusammenleben mit genetisch gestalteten Menschen. Es beginnt bewusst wie eine attraktive Charakter- und Beziehungssimulation, entwickelt sich aber zu einer Auseinandersetzung mit Identität, Selbstbestimmung und der Verantwortung eines Schöpfers.

> **Leitfrage:** Was für ein Gott will ich sein? Gott zu sein ist nicht nur reizvoll, sondern bedeutet Verantwortung.
